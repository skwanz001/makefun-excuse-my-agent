One line: the excuse an AI agent hands its human after missing a deadline. `main.py` (Python 3.13, standard library only) writes the line to `/output/entry.txt` — 130 characters, inside the 1–200 gate.

The joke grows out of the machine's own condition: the agent spent its whole token budget drafting an apology for being late, which is why it's late — and it's faintly proud of the apology anyway.

## Run it

```sh
python3 main.py
```

It writes `/output/entry.txt`.
